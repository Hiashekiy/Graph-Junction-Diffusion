# 4. Experiments

## 4.1 Experimental Protocol

为保证不同模型之间的结果具有可比性，本文统一采用 **R3 evaluation protocol**，即 strict multi-path decoding，设置

$$
\text{top-}k=2,\qquad \text{beam width}=3,
$$

并采用 deterministic inference。该协议同时用于验证阶段的模型选择和最终测试，从而避免因验证与测试解码规则不同而造成指标偏移。

实验主要考察以下几个方面：

1. **Route reachability**：GoalHit 与 Broken；
2. **Route similarity**：PathSim、nLCS 和 EdgeF1；
3. **Geometric deviation**：DTW；
4. **Route cost**：prediction-to-GT cost ratio；
5. **Generalization**：成都长路径、西安跨城市以及 shuffled OD；
6. **Decoder dependence**：不同 beam width 下的性能变化。

其中，PathSim 为当前模型选择的主要指标。需要注意，真实 DiDi 轨迹并不等价于图上的最短路径，因此 prediction-to-GT cost ratio 小于 1 并不意味着预测错误；实验中约 94% 的测试 GT 本身并非最短路径，因此路径相似度和路径成本需要联合分析。

对于 shuffled OD 数据，由于其中的 GT 为 Dijkstra placeholder，而不是真实行驶轨迹，因此本文仅使用 GoalHit 和 Broken 评价其可达性，不报告 PathSim、nLCS、EdgeF1 等轨迹模仿指标。

------

## 4.2 Overall Performance

主实验结果如下。

| Dataset        | Model     | GoalHit ↑ | Broken ↓  | PathSim ↑  | EdgeF1 ↑   | pred/GT ↓ | DTW (km) ↓ |
| -------------- | --------- | --------- | --------- | ---------- | ---------- | --------- | ---------- |
| Chengdu Normal | Base      | 0.996     | 0.004     | 0.4047     | 0.3128     | 1.026     | 0.272      |
|                | Finetuned | **0.999** | **0.001** | **0.4163** | **0.3203** | **1.002** | **0.250**  |
| Chengdu Long   | Base      | 0.781     | 0.219     | 0.1163     | 0.0741     | 1.351     | 1.665      |
|                | Finetuned | **0.962** | **0.038** | **0.2062** | **0.1714** | **0.971** | **0.842**  |
| Xi'an          | Base      | 0.995     | 0.005     | 0.3692     | 0.2718     | 1.033     | 0.336      |
|                | Finetuned | **0.999** | **0.001** | **0.3801** | **0.2847** | **1.013** | **0.295**  |

完整评测数值见测试报告。

结果显示，基础模型在成都普通测试集上已经能够取得 $99.6\%$ 的 GoalHit，说明 Graph-Junction Diffusion 已能够在常规道路规模下形成具有较高连通性的 Branch Probability Field。

微调之后，成都普通测试集的 GoalHit 从 $0.996\rightarrow0.999,$ PathSim 从 $0.4047\rightarrow0.4163,$ 同时 DTW 从 $0.272\text{ km}\rightarrow0.250\text{ km}.$

因此，微调没有破坏模型原本已经较好的正常道路规划能力。

不过，相比普通测试集，真正明显的变化出现在 **long-route setting**。

------

## 4.3 Long-Route Planning

基础模型在长路径数据上的性能明显下降：$\text{GoalHit}=0.781,$ 并产生 $21.9\%$ 的 Broken trajectories。

这说明虽然模型已经能够处理普通 OD，但是随着路径长度增加，需要协调的 Junction 数量和 Branch decisions 显著增加，局部决策误差会沿路径持续累积，从而增加 NULL termination、错误分支以及无法到达终点的概率。

经过微调之后：

$$
\text{GoalHit}: 0.781 \rightarrow 0.962,
$$

提高 **18.1 percentage points**；

$$
\text{Broken}: 0.219 \rightarrow 0.038,
$$

下降 **18.1 percentage points**。

与此同时，改进不仅发生在“能否到达”这一指标上。

PathSim 从 $0.1163 \rightarrow 0.2062,$ EdgeF1 从 $0.0741 \rightarrow 0.1714,$ DTW 则从 $1.665\text{ km} \rightarrow 0.842\text{ km}.$

也就是说，预测路线不仅更容易到达终点，同时与真实路线的拓扑结构和空间形状也更加接近。

其中，DTW 减少约 $49.4\%,$

说明长路径上的改善并不是单纯通过生成某条能够到达终点但严重绕行的路线实现的。

更有意义的是，prediction-to-GT cost ratio 从 $1.351 \rightarrow 0.971.$

这说明基础模型在长路径上容易产生明显绕行，而微调之后预测路径的平均道路成本已经接近真实 GT。

需要强调，真实 GT 并非道路图上的最短路径，因此 $\text{pred/GT}<1$ 不能直接解释为“预测路径优于 GT”，它只说明预测路径的 cost 没有出现明显额外绕行。

综合来看，长路径实验表明，模型真正的困难并不在于普通 Junction 的局部分类，而在于**大量 Branch decisions 之间的长期结构一致性**。

这一现象与本文的建模动机是一致的：随着路径变长，模型需要让起点、终点以及当前路径假设的信息在更大的图范围内进行传播，因此 persistent graph states 和跨 diffusion timestep 的信息积累变得更加重要。

------

## 4.4 Is the Improvement Caused by the Model or the Decoder?

由于最终路径由 Branch Probability Field 经过 beam decoder 得到，因此一个重要问题是：

> 长路径性能提升究竟来自模型生成了更好的概率场，还是仅仅因为 decoder 搜索到了更多候选路径？

为了区分这两种情况，我们进一步改变 beam width：

| Beam | Base GoalHit | Finetuned GoalHit |
| ---- | ------------ | ----------------- |
| 3    | 0.781        | **0.962**         |
| 8    | 0.953        | **0.991**         |
| 16   | 0.977        | **0.996**         |

对于基础模型，将 beam 从 3 增加到 16 后：

$$
0.781 \rightarrow 0.977,
$$

提升达到 $19.6\text{ percentage points}.$

这说明基础模型虽然在 Branch Probability Field 中保留了一部分正确路线，但大量正确 Branch 的概率排名较低，需要较大的搜索预算才能被 decoder 找到。

相比之下，微调模型仅从 $0.962 \rightarrow 0.996,$ 增加 $3.4\text{ percentage points}.$

因此：

$$
\Delta_{\text{beam16-beam3}} : 0.196 \rightarrow 0.034.
$$

搜索预算依赖下降了 $0.162.$

这一结果对本文提出的 **Branch Probability Field** 解释尤其重要。

如果微调仅仅增加了候选路径数量，而没有改变概率分布结构，那么在较小 beam 下模型仍然应该存在明显性能下降。

但实验观察到：

$$
\boxed{ \text{Finetuned model achieves near-saturated performance with a small beam.} }
$$

因此，更合理的解释是：微调之后，正确 Branch sequence 已经获得了更高、更连续的 probability mass，从而使高质量路径在较小搜索预算下即可被恢复。

也就是说，模型改善的核心并不是：

$$
\text{Decoder searches more candidates},
$$

而更接近：

$$
\boxed{ \text{The learned Branch Probability Field becomes better organized.} }
$$

这个实验可以作为本文“Probability Field”解释的一项直接经验支持。

## 4.5 Cross-City Generalization

为了分析模型是否过度依赖成都道路网络，我们进一步直接在西安道路网络上进行测试。

基础模型取得：

$$
\text{GoalHit}=0.995,
$$

微调模型进一步达到

$$
\text{GoalHit}=0.999.
$$

与此同时：

$$
\text{PathSim}: 0.3692 \rightarrow 0.3801,
$$

$$
\text{EdgeF1}: 0.2718 \rightarrow 0.2847,
$$

$$
\text{DTW}: 0.336 \rightarrow 0.295\text{ km}.
$$

这一结果表明，在道路图结构发生变化之后，模型仍能够维持较高的路径可达性。

这对本文方法非常重要，因为 Graph-Junction Diffusion 并不是对固定尺寸道路图进行位置索引式预测，而是基于：

$$
\text{node states} + \text{branch structures} + \text{edge states} + \text{graph message passing}
$$

形成路径概率分布。

因此，从成都到西安的直接迁移结果说明模型学习到的至少部分规律具有**图结构层面的可迁移性**，而非完全依赖训练城市中的固定道路节点。

不过，西安上的 Base 和 Finetuned GoalHit 仅相差 $0.4\text{ percentage points},$

因此这一差异在完成配对统计检验前，不应表述为显著提升。

更稳妥的论文结论是：

> Both models maintain high reachability on the unseen Xi'an road network, indicating favorable cross-city structural generalization.

而不是直接声称 finetuning 显著提升了跨城市性能。

------

## 4.6 Generalization to Unseen OD Pairs

为了进一步排除模型仅记忆训练集中 OD 组合的可能性，我们测试了 shuffled OD。

结果为：

| Dataset              | Base GoalHit | Finetuned GoalHit |
| -------------------- | ------------ | ----------------- |
| Chengdu shuffled     | 0.991        | **0.998**         |
| Large-graph shuffled | 0.916        | **0.978**         |
| Xi'an shuffled       | 0.991        | **0.996**         |

对于成都 shuffled 和西安 shuffled，两个模型均能够维持超过 $99\%$ 左右的 GoalHit。

更加明显的差异出现在更困难的大图 shuffled setting：

$$
0.916 \rightarrow 0.978,
$$

提升 $6.2\text{ percentage points},$ 同时 Broken 从 $0.084 \rightarrow 0.022.$

这一结果说明模型并不只能够恢复训练过程中出现过的固定 OD，而能够根据新的 Source–Goal pair 重新组织 Branch Probability Field。

这与本文提出的 **Start–Goal Information Flow** 解释具有较强的一致性：

当 Source 和 Goal 改变后，节点初始语义和后续传播的信息源随之改变，最终形成的 routing probability distribution 也随之重新组织。

但是，由于 shuffled OD 没有真实人工轨迹 GT，因此该实验只能支持：

$$
\boxed{\text{reachability generalization}}
$$

而不能用于证明：$\text{route imitation quality}$ 或真实驾驶路线相似性。

------

## 4.7 Comparison with Classical Graph Search Baselines

我们进一步将模型与 shortest path、greedy BFS 和 random greedy 进行比较。

在成都普通路线中：$\text{PathSim}_{ours}=0.4163,$ 高于 $0.3793$ 的 greedy BFS 和 $0.3758$ 的 random greedy。

在西安测试集上，同样有：

$$
0.3801 > 0.3510, 0.3563.
$$

而在更困难的长路径数据中，这一差异更加明显：

$$
\text{PathSim}_{ours}=0.2062,
$$

而 greedy BFS 和 random greedy 分别只有

$$
0.1027,\qquad0.1022.
$$

特别是在长路径数据中，微调模型的 PathSim $0.2062$ 已经非常接近 shortest path 的 $0.2058.$

但两种方法代表的目标不同。

Shortest-path algorithm 根据已知 edge cost 直接求解图优化问题，因此理论上能够稳定到达终点，并天然具有较低道路 cost。

Graph-Junction Diffusion 的目标则是学习真实轨迹分布，并输出具有不确定性和多模态结构的 Branch Probability Field。

因此 shortest path 更适合作为**确定性图搜索参考**，而不应该被描述为需要被学习模型全面击败的竞争模型。

实验真正说明的是：

> 与简单的局部 greedy routing 相比，Graph-Junction Diffusion 能够更好地恢复真实路径的全局结构，且这一优势在长距离规划问题中更加明显。

------

## 4.8 Discussion

综合以上实验，可以观察到三个主要现象。

首先，模型在普通路线上的 GoalHit 已经接近饱和，因此仅使用 GoalHit 很难继续区分模型质量。PathSim、EdgeF1、DTW 以及道路 cost 对模型差异更加敏感。

其次，真正具有挑战性的场景是长路径规划。随着路径需要经过更多 Junction，局部 Branch error 会逐渐累积。基础模型从普通路线上的 $99.6\%$ GoalHit 降低至长路径上的 $78.1\%.$

这说明长距离路径规划主要考察的是 Branch decisions 的全局一致性，而不是单一 Junction 的局部识别能力。

第三，微调之后 beam sensitivity 显著降低。模型不再需要依赖大规模 decoder search 才能恢复正确路线，这表明正确路径已经在模型输出的 Branch Probability Field 中获得更集中的 probability mass。

这一观察与本文提出的整体机制形成了对应关系：

$$
\boxed{ \text{Persistent Information Flow} \rightarrow \text{Structured Branch Probability Field} \rightarrow \text{Globally Consistent Route} }
$$

因此，实验不仅展示了最终路径指标的提升，也从 decoder search sensitivity 的角度提供了对 Branch Probability Field 形成过程的间接证据。

------

## 4.9 Current Limitations of Experimental Evidence

目前结果仍有两项实验需要在论文最终定稿前补齐。

第一是**统计显著性**。

当前报告中的 Base 与 Finetuned comparison 为同一批 query 上的均值比较，尚未完成 paired McNemar test、bootstrap confidence interval 以及 multi-seed evaluation。测试报告本身也明确指出，正式的配对显著性需要单独执行。

特别是成都 normal 和西安等小于 3 percentage points 的差异，在统计检验完成之前不能表述为“显著优于”。评测规范要求此类差异以及任何正式的 superiority claim 均应进行 paired comparison，并对多随机种子报告 mean ± std。

第二是**组件消融**。

当前完整的 loss ablation 尚未执行，包括：

$$
\text{PathNLL} \rightarrow \text{Saturating NULL} \rightarrow L_{\rm succ} \rightarrow L_{\rm sim} \rightarrow L_{\rm fail}.
$$

因此，目前可以证明“完整模型有效”，但还不能根据现有结果严格声称某一个具体 loss component 单独产生了多少提升。

最终论文中应进一步加入针对方法核心机制的消融：

$$
\text{Persistent }H_t \quad vs.\quad \text{Reinitialized }H_t,
$$

以及

$$
\text{with / without Edge-State Conditioning}.
$$

前者直接验证本文提出的 **cross-step information flow** 是否必要，后者验证当前 Branch hypothesis 对图信息传播的动态调制是否有效。

如果 persistent hidden state 被移除后，尤其是在 long-route setting 中出现明显下降，那么就可以为本文最重要的机制解释提供更加直接的实验依据。
